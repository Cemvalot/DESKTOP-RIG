## Installation

1. Clone the repository
2. `npm install`
3. Copy `.env.example` to `.env` and configure LAN settings
4. `npm start`
5. Access the kiosk interface from authorized devices on your LAN

## Usage

### Usage

Access the kiosk from any device on your local network. The app provides
remote control of PC/tablet displays with virtual keyboard, trackpad, and
display management. Authentication is required for LAN access.
